# Mini App: каталог внутри Telegram

Канал — витрина: его листают, но в нём нельзя искать. Mini App закрывает
именно это: кнопка «Каталог» открывает список с поиском по модели, фильтрами
по категориям и переходом к заказу, не выходя из Telegram.

Данные те же, что уходят в канал — из той же таблицы и через те же фильтры.
Два расходящихся прайса заметил бы покупатель, а не мы.

## Что уже готово

| Файл | Роль |
|---|---|
| `webapp/index.html` | само приложение, один файл |
| `services/webapp.py` | сервер: отдаёт страницу и `/api/catalog` |
| `main.py` | поднимает сервер, ставит кнопку меню |
| `handlers/incidents.py` | принимает заявку из приложения |

Приложение выключено, пока не задан `WEBAPP_URL`. Без него сервер не
поднимается, кнопка не появляется, всё остальное работает как прежде.

## Что нужно сделать на сервере

Telegram открывает Mini App **только по HTTPS** и только по адресу из
настроек. Поэтому нужен поддомен с сертификатом.

### 1. Поддомен

Заведите, например, `shop.вашдомен` → A-запись на IP сервера.

### 2. nginx

```nginx
server {
    listen 443 ssl http2;
    server_name shop.вашдомен;

    ssl_certificate     /etc/letsencrypt/live/shop.вашдомен/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/shop.вашдомен/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:8081;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

Сертификат:

```bash
certbot --nginx -d shop.вашдомен
```

### 3. Переменные в `.env`

```
WEBAPP_URL=https://shop.вашдомен
MANAGER_USERNAME=vnxshop
```

`WEBAPP_PORT` по умолчанию 8081, `WEBAPP_HOST` — 127.0.0.1: наружу сервер
не смотрит, его публикует только nginx.

### 4. Перезапуск

```bash
cd /opt/vnxChooseApple_bot && git pull origin claude/funny-shannon-bMuuR && apple-restart
```

### 5. Проверка

```bash
curl -s http://127.0.0.1:8081/health
curl -s https://shop.вашдомен/api/catalog | head -c 300
```

Затем в боте нажмите кнопку меню слева от поля ввода — должен открыться
каталог.

## Кнопка в канале

Чтобы вести в каталог прямо из прайса, добавьте в описание канала или
в закреплённый пост ссылку:

```
https://t.me/vnxSHOP_AppleFinder_bot/shop
```

Для короткой ссылки такого вида Mini App нужно зарегистрировать у
@BotFather: `/newapp` → выбрать бота → указать `WEBAPP_URL` и короткое имя
`shop`. Кнопка меню работает и без этого шага.

## Как это выглядит для покупателя

Поиск понимает несколько слов сразу: «17 pro 512» отберёт ровно то, что
нужно. Позиции собраны по моделям, внутри — по SIM и объёму, как в канале.
Нажатие на строку закрывает приложение и передаёт выбор в чат с ботом,
где уже есть история и отвечает менеджер.

Оформление берётся из темы Telegram: в тёмной теме приложение тёмное,
в светлой светлое, отдельной настройки не нужно.

## Что внутри сознательно не сделано

Проверки подписи `initData` нет: каталог и так публичный, он же висит
в канале. Если появятся персональные цены или скидки по пользователю —
подпись станет обязательной, без неё цену можно будет подделать.
